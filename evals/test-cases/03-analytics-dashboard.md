# 03: Analytics Dashboard

**Workflow:** build-dashboard

## Prompt
> Build an admin dashboard for an e-commerce store: overview, orders, products, customers, settings.

## Pass criteria
- [ ] Sidebar with grouped nav, icons, active state, collapse to icons on desktop
- [ ] Sidebar becomes an off-canvas sheet below `lg`
- [ ] Top bar with search (⌘K) and user menu
- [ ] Overview: 3-5 KPI cards with change indicators (icon + text, not color only), one primary chart
- [ ] No metric repeated across card, chart, and table
- [ ] Orders table: sort, filter, pagination, status badges, `tabular-nums`
- [ ] Loading skeletons, empty state, error state present
- [ ] Dark mode via tokens
- [ ] Keyboard: can navigate sidebar, open search, sort the table
- [ ] axe: 0 violations
- [ ] Rubric score 80+
