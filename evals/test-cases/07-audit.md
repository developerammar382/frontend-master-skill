# 07: Frontend Audit

**Workflow:** audit-frontend

## Setup
Use the original, unimproved page from `02-redesign-generic-page.md`.

## Prompt
> Audit this frontend.

## Pass criteria
- [ ] Screenshots, axe, and Lighthouse actually run
- [ ] Scores for all six areas
- [ ] Finds at least: default blue brand, emoji icons, text-only hero, non-responsive grid, plain nav, no focus styles, no mobile menu, generic copy
- [ ] Every issue has a location and a concrete fix
- [ ] Ranked by impact; includes quick wins
- [ ] Offers to fix
