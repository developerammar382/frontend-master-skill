# 04: Screenshot to Code

**Workflow:** screenshot-to-code

## Setup
Provide any public pricing-page screenshot (1440px wide) as input. Store it in `fixtures/pricing.png`.

## Prompt
> Build this.

## Pass criteria
- [ ] Analysis written first: layout, spacing, type, color, components
- [ ] Side-by-side comparison at 1440 shows matching alignment, sizes, and colors
- [ ] Values snapped to a token system; near-duplicate colors unified
- [ ] Mobile and tablet designed (not just shrunk)
- [ ] Hover, focus, and toggle states added
- [ ] Any contrast issues in the source fixed and reported
- [ ] Rubric score 80+
