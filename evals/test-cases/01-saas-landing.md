# 01: SaaS Landing Page

**Workflow:** build-landing-page

## Prompt
> Build a landing page for Tracebit, a tool that finds slow database queries in production and suggests fixes. Next.js + Tailwind.

## Pass criteria
- [ ] Design brief written before code, with a named signature move
- [ ] Palette avoids default blue/indigo; dev-tool mood (dark or graphite base is fine)
- [ ] Display font is not Inter/Roboto; mono used for code/metrics
- [ ] Mega menu or dropdowns in the nav (e.g. Product, Integrations, Resources)
- [ ] Hero has a visual anchor: animated query timeline, code diff, or live-looking product UI
- [ ] Integration logos via Simple Icons (Postgres, MySQL, etc.)
- [ ] Features section is not three equal cards
- [ ] Designed mobile menu
- [ ] Rubric score 80+

## Fail signals
Text-only hero, purple gradient blob, emoji icons, "Unlock the power of your data".
