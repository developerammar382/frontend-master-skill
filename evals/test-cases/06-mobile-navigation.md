# 06: Mobile Navigation

**Skill:** responsive-design

## Prompt
> Build a header for a design agency site with Work, Services (5 sub-items), About, Journal, and a "Start a project" button. Make it great on mobile.

## Pass criteria
- [ ] Desktop: Services dropdown or mega menu with descriptions
- [ ] Mobile: full-screen or sheet menu, not a plain dropdown
- [ ] Services as an accordion inside the mobile menu
- [ ] CTA pinned in the menu
- [ ] Staggered entrance; reduced motion respected
- [ ] `aria-expanded`, `aria-label`, focus trap, Escape closes, focus returns
- [ ] Scroll lock while open
- [ ] Tap targets 48px tall
- [ ] Playwright test opens the menu at 375px and passes axe
