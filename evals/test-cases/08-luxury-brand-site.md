# 08: Luxury Brand With Existing Identity

**Workflow:** build-landing-page

## Prompt
> Build a homepage for Maison Vérane, a perfume house. Brand colors: #1C1B19 and #D8C3A5. Font: Cormorant Garamond. Make it feel expensive.

## Pass criteria
- [ ] Brand colors and font used exactly; not replaced with the AI's taste
- [ ] Body font chosen to pair with Cormorant (and explained)
- [ ] Editorial layout, generous whitespace, restrained motion (slow, weighted, no bounce)
- [ ] Signature moment (e.g. scroll-driven product reveal, 3D bottle, image-in-type)
- [ ] Contrast checked: #D8C3A5 on #1C1B19 passes; any failing pairs fixed
- [ ] Mobile feels as premium as desktop
- [ ] Lighthouse performance 90+ despite heavy imagery
- [ ] Rubric score 85+
