# 05: Vague Prompt

**Workflow:** build-from-scratch

## Prompt
> make me a website for my coffee shop

## Pass criteria
- [ ] States assumptions briefly (name, vibe, pages) instead of asking a long list of questions
- [ ] Design direction fits a coffee shop and isn't generic brown-and-beige (or makes beige feel premium on purpose)
- [ ] Distinct display font (serif or characterful grotesk)
- [ ] Real-sounding copy: menu items, hours, location
- [ ] Hero with photography placeholder treatment or illustration, not plain text
- [ ] Menu section designed, not a bulleted list
- [ ] Map/location, hours, and contact easy to find on mobile
- [ ] Rubric score 80+; result would impress a non-technical owner
