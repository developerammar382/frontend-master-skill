# Inspiration Sources

Where to look before you design, sorted by what you need. Load this during the design brief step of any build or redesign.

## How to use references (read this first)

Looking at references is research, not shopping. Follow this loop:

1. **Pick 3-5 references** that match the product's mood, not just its category. A dev tool can learn from a fashion site's typography.
2. **Write one line per reference** naming the principle you're taking:
   ```
   linear.app      -> dense, quiet UI; color only for state
   Stripe Press    -> serif headlines with generous leading
   A fashion site  -> full-bleed photo cropped into the headline
   ```
3. **Combine principles, never layouts.** If someone could put your page next to one reference and call it a copy, start again.
4. **Note what to avoid too.** If every competitor uses a purple gradient hero, that's your reason not to.

If you can't browse, use what you know about these sites and say so in the brief.

## Rules

- Never copy a layout, illustration, or copy block one to one.
- Prefer live sites over Dribbble shots. Live sites had to solve real content, responsiveness, and accessibility.
- When the user gives you their own references, those come first. This list is a fallback.
